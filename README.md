# PySpark & AWS Data Engineering Course (Python)

Este repositorio contiene ejercicios, retos y proyectos prácticos enfocados en el aprendizaje y dominio de **Python para Ingeniería de Datos**, cubriendo desde las bases del lenguaje hasta el procesamiento distribuido con **Apache Spark (PySpark)** y su integración con servicios de **AWS**.

## 🚀 Contenido del Repositorio

El contenido está organizado de forma progresiva en los siguientes módulos:

### 📁 02. Estructuras de Datos y Control de Flujo (`/02-data-structures`)
Fundamentos esenciales de Python aplicados a la manipulación de datos:
*   **Tipos de datos y estructuras:** Listas, tuplas, diccionarios y sets.
*   **Control de flujo:** Estructuras condicionales, bucles `for` y `while`, control con `break` y `continue`.
*   **Gran Integrador:** Retos prácticos para unificar los conceptos aprendidos.

### 📁 03. Programación Avanzada (`/03-funciones-y-excepciones`)
Buenas prácticas, modularización y programación orientada a objetos:
*   **Funciones:** Declaración, argumentos, alcances y funciones lambda.
*   **Excepciones:** Control de errores y robustez del código.
*   **POO (Programación Orientada a Objetos):** Clases, objetos, herencia y encapsulamiento.
*   **Gran Integrador:** Aplicación en casos de uso de ingeniería de datos.

### 📁 04. Apache Spark y PySpark (`/04.-Spark`)
Procesamiento de datos a gran escala y de forma distribuida:
*   **SparkSession y RDDs:** Configuración y conceptos básicos de computación distribuida.
*   **DataFrames:** Manipulación, transformaciones, uniones (joins) y agregaciones de datos.
*   **Spark SQL:** Consultas SQL directamente sobre DataFrames.
*   **Lectura y Escritura:** Integración con formatos como CSV, Parquet y JSON.
*   **Manejo de nulos:** Limpieza y depuración de datos (Data Cleansing).

## 🛠️ Requisitos previos

Para ejecutar los cuadernos y scripts de este repositorio necesitarás:
*   Python 3.10 o superior.
*   Java Development Kit (JDK) 8 o 11 (requerido para Spark).
*   Apache Spark instalado localmente o configurado en tu entorno virtual.
*   `pyspark` instalado via `pip`.
